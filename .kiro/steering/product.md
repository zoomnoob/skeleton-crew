# Product

Skeleton Crew ships two small, unrelated tools so that each one can be built,
run and released on its own:

- **word-frequency-cli** — a terminal tool that reports the top words of any
  text file. Success measure: correct counts on a plain-text file, no third
  party install step.
- **pomodoro-web** — a browser timer for 25 minute focus / 5 minute break
  cycles. Success measure: opens from `file://` with no build step.

Non-goals: accounts, sync, analytics, shared UI kit, a root-level build system.
